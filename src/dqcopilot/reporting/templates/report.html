How the score is calculated

The score is deterministic and reproducible. Each finding contributes a penalty equal to its severity weight multiplied by the fraction of rows it affects: 

penalty(finding) = severity_weight x affected_ratio x 100

severity weights: critical 1.0 | high 0.6 | medium 0.3 | low 0.1 | info 0.0

column_score = clamp(100 - SUM(penalties for that column), 0, 100)
overall      = clamp(mean(column_scores) - SUM(dataset-level penalties), 0, 100)

Only deterministic findings count. AI suggestions never move the score, so the number is the same with or without an API key. Dataset-level penalty applied here: {{ score.dataset_penalty }}.
